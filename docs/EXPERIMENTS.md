# Creative experiments

The agent proposes alternative concepts, chooses a hypothesis, generates work, and reviews actual output before publication. Its style remains revisable; neither a fixed persona nor a rigid aesthetic template is assigned.

Operator reference media, source URLs, detailed visual studies and feedback are private deployment inputs. They are loaded only by server functions from the ignored private/ directory and are not public repository assets. Public experiment records expose selected hypotheses, alternatives, decisions and resulting original work, but exclude the private influence/study object.

Public clones use synthetic test fixtures. Real reference-dependent generation fails closed when private inputs are not configured. See PRIVACY.md for the boundary and publication checks.

## Diversity before generation

Both ordinary planning and experimental planning receive the eight latest distinct published media jobs, not eight events from the same pipeline. Choices compare construction, composition, emotion, caption function and movement. No genre is preferred or banned, and meaningful series may continue. Experimental alternatives expose visualMechanism, viewerExperience, diversityComparison and continuationReason. The studio revision receives the same comparison context. Historic success claims are hypotheses, not proof of audience preference. Criticism remains advisory; this is not a new publication veto. One image commissioning check verifies the revised planner with private reference pixels.
